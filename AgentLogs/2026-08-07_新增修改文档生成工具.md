# 新增修改文档生成工具

- 日期：2026-08-07
- 任务：新增修改文档生成工具

## 完成的工作

- 新增 Unity MCP Tool：`change-report-generate`。
- Tool 会根据当前日期和任务名称自动生成 Markdown 修改报告。
- 报告固定包含完成的工作、修改文件和使用说明三个部分。
- 默认输出至 `Design/修改文档`，同名文件会自动追加数字后缀，避免覆盖历史报告。
- 对输出路径进行项目目录边界校验，拒绝绝对路径和目录穿越。
- 通过 Unity MCP 的 Skill 生成器生成配套 `SKILL.md`，用于约束修改任务结束后调用该工具。

## 修改文件

- `.claude/skills/change-report-generate/SKILL.md`
- `Assets/Editor/Tools/Tool_ChangeReport.cs`

## 使用说明

完成一次修改并确认结果后调用：

```powershell
unity-mcp-cli run-tool change-report-generate --input-file report.json
```

`report.json` 示例：

```json
{
  "taskName": "实现角色背包",
  "workSummary": "- 新增背包数据结构。\n- 实现物品增删接口。",
  "usageInstructions": "通过 InventoryService.AddItem(...) 添加物品。",
  "changedFiles": ["Assets/Scripts/Inventory/InventoryService.cs"]
}
```

`taskName` 应简短概括任务；`workSummary` 和 `usageInstructions` 支持 Markdown；`changedFiles` 只填写本次任务实际修改的文件。未指定 `outputDirectory` 时，报告写入 `Design/修改文档`。
