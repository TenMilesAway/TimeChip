# 变量命名规范 Skill

- 日期：2026-08-13
- 任务：变量命名规范 Skill

## 完成的工作

新增 `variable-naming-convention-get` Unity MCP Skill/Tool。Skill 明确规定：除常量和静态值外，声明变量使用 `_camelCase`；供外部调用的 Getter 使用无下划线的 PascalCase。规则同时要求保持已有公开 API 兼容性，并禁止不安全的批量文本重命名。

## 修改文件

- `.claude/skills/variable-naming-convention-get/SKILL.md`
- `Assets/Editor/Tools/Tool_VariableNamingConvention.cs`
- `Assets/Editor/Tools/Tool_VariableNamingConvention.cs.meta`

## 使用说明

在创建或修改 C# 脚本前调用 `variable-naming-convention-get` 获取规则；编写变量时遵守返回的命名规范。
